Module 05 · GUI 与一键部署

可视化后台 + 一键发布到 GitHub Pages

GUI 是一个 Vue 3 + Pinia + Tailwind 的 Web SPA 子包（gui/），把 CLI 的能力搬到浏览器。部署则是一条命令走完"预检 → 构建 → 推送 → 清理"。

GUI Admin

五个模块，把日常写作搬到浏览器

启动 GUI 只需一条命令：pnpm gui:dev。它会在 3000 端口打开一个 Web SPA，并把 API 通过 Vite 中间件挂在同一个端口，不需要再开第二个窗口。

📊
工作台

站点统计（文章数、总字数、本月新增、累计访问）、分类分布、最近活动时间线、快捷入口。

✏️
Markdown 编辑器

左右分栏编辑/预览、字数/行数/阅读时长实时统计、目录大纲、Mermaid 图表渲染、30s 自动保存草稿、Ctrl+S 保存。

📁

列表 + 字数/浏览量列、搜索、多维筛选（分类 / 标签 / 状态）、多列排序、批量多选（发布 / 标草稿 / 删除）。

🚀

调用 post d 推送 gh-pages，SSE 实时日志、心跳动画、停止按钮、日志搜索+级别过滤+自动滚屏。

⚠
小心 gh-pages 分支

deploy 阶段会用 --force 推送到 gh-pages 分支（这与 main 是两个独立的分支）。如果团队里有其他人也在操作这个分支，请先沟通；个人项目则无此顾虑。

不一定要用 GitHub Pages——五种部署方式

FilePress Blog 的构建产物 .vitepress/dist/ 是纯静态文件，可以托管到任何静态服务。下面是常见平台的对比：

GitHub Pages
最省心 · 适合个人项目
Vercel
自动 HTTPS · 全球 CDN
Netlify
表单 + Functions · 适合带交互的站点
Cloudflare Pages
边缘渲染 · 免费额度大
Nginx
完全自主 · 国内访问友好
OSS / COS
阿里云 / 腾讯云对象存储
nginx.conf 片段 

server {
  listen 80;
  server_name blog.example.com;
  root /var/www/filepress-blog/.vitepress/dist;
  index index.html;

  location / {
    try_files $uri $uri/ =404;
  }

  # 启用 Gzip 压缩
  gzip on;
  gzip_types text/plain text/css application/json application/javascript;
}
PLAIN ENGLISH

监听 80 端口，绑定域名。

站点根目录指向 .vitepress/dist/。

try_files 先按路径找文件，找不到再 fallback 到 404（VitePress 自带 404.md 友好页）。

开启 Gzip 让 JS / CSS 资源体积更小。

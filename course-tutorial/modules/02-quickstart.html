Module 02 · 快速开始

从 0 到 1：环境、安装、第一次跑起来

本模块把安装到本地预览的全过程拆解成 5 步。每一步都给出确切命令、可预期的输出，以及最常见的踩坑提醒。

Step 0 · 准备

先确认你的机器"够格"

FilePress Blog 对环境只有两条硬性要求：Node.js ≥ 20，pnpm ≥ 9。除此之外没有任何外部依赖（不装 MySQL、不装 Redis、不配 Nginx）。

01
Node.js ≥ 20

建议用 nvm 管理多版本；macOS / Linux 用户 nvm install 20 && nvm use 20，Windows 使用 nvm-windows。

02
pnpm ≥ 9

npm i -g pnpm。FilePress Blog 锁定了 esbuild / sharp / vue-demi 的 build 脚本，pnpm-workspace.yaml 已在仓库中配置。

03
Git

仅当你准备 git push 部署到 GitHub Pages 时需要，本地预览不强制安装。

ⓘ

Why pnpm, not npm?

pnpm 的硬链接机制能让 node_modules 在多项目间共享，安装速度比 npm 快 2-3 倍，磁盘占用也更小。FilePress Blog 的 CI 工作流也基于 pnpm 编写。

BASH 

# 1. 克隆 / 进入工程
git clone https://github.com/dcyyd/dcyyd.github.io.git
cd dcyyd.github.io

# 2. 安装依赖（推荐 pnpm ≥ 9）
pnpm install

# 3. 启动开发服务器（默认 http://localhost:5173）
pnpm dev

# 4. 另开终端，创建文章，Vite 热更新自动生效
pnpm post n my-first-post -T "我的第一篇博客" -t "随笔,入门"

# 5. 一键部署到 GitHub Pages
pnpm post d -y

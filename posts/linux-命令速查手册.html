Linux命令速查手册

本文整理了Linux系统中常用的命令，涵盖文件与目录操作、权限管理、用户与群组管理、进程管理、系统信息查看、网络管理、软件包管理、文本处理、压缩与解压等九大核心场景，是Linux初学者和运维人员的实用速查手册。

Linux命令行运维系统管理

一、文件与目录操作

1. 目录浏览

Bash
123456789101112131415
# 查看当前工作目录
pwd

# 列出当前目录下的文件和文件夹
ls

# 列出当前目录下的所有文件和文件夹，包括隐藏文件
ls -a

# 以长格式列出文件和文件夹的详细信息
ls -l

# 递归列出当前目录及其子目录下的所有文件和文件夹
ls -R

2. 目录切换

Bash
123456789
# 切换到指定目录
cd /path/to/directory

# 切换到上一级目录
cd ..

# 切换到用户主目录
cd ~

3. 目录与文件创建

Bash
123456789
# 创建新目录
mkdir new_directory

# 创建多级目录
mkdir -p path/to/new/directory

# 创建新文件
touch new_file.txt

4. 目录与文件删除

Bash
123456789101112
# 删除空目录
rmdir empty_directory

# 删除文件
rm file.txt

# 递归删除目录及其内容
rm -r directory

# 强制删除文件或目录，不提示确认
rm -f file_or_directory

5. 目录与文件移动和重命名

Bash
123456
# 移动文件或目录到指定位置
mv source_file_or_directory destination_path

# 重命名文件或目录
mv old_name new_name

6. 目录与文件复制

Bash
123456
# 复制文件
cp source_file destination_path

# 递归复制目录及其内容
cp -r source_directory destination_path

7. 文件内容查看

Bash
12345678910111213141516
# 查看文件内容
cat file.txt

# 分页查看文件内容
more file.txt
less file.txt

# 查看文件前几行
head -n 10 file.txt

# 查看文件后几行
tail -n 10 file.txt

# 实时监控文件内容变化
tail -f file.txt

二、权限管理

1. 查看文件权限

Bash
123
# 以长格式列出文件和文件夹的详细信息，包含权限信息
ls -l

2. 修改文件权限

Bash
123456
# 使用数字模式修改权限，如 755 表示所有者具有读、写、执行权限，群组和其他用户具有读、执行权限
chmod 755 file_or_directory

# 使用符号模式修改权限，如 u+x 表示给所有者添加执行权限
chmod u+x file

3. 修改文件所有者和所属群组

Bash
123456789
# 修改文件或目录的所有者
chown new_owner file_or_directory

# 修改文件或目录的所属群组
chgrp new_group file_or_directory

# 同时修改所有者和所属群组
chown new_owner:new_group file_or_directory

三、用户与群组管理

1. 用户管理

Bash
123456789101112
# 创建新用户
useradd new_user

# 设置用户密码
passwd new_user

# 删除用户
userdel new_user

# 查看当前登录用户
whoami

2. 群组管理

Bash
123456789
# 创建新群组
groupadd new_group

# 删除群组
groupdel new_group

# 将用户添加到群组
usermod -aG new_group user

四、进程管理

1. 查看进程

Bash
12345678910
# 查看当前运行的进程
ps

# 查看所有进程
ps -ef

# 实时监控进程活动
top
htop

2. 终止进程

Bash
123456
# 终止指定进程 ID 的进程
kill <PID>

# 强制终止指定进程 ID 的进程
kill -9 <PID>

3. 后台进程管理

Bash
1234567
# 将当前进程放到后台运行
Ctrl + Z
bg

# 将后台进程放到前台运行
fg

五、系统信息查看

1. 查看系统信息

Bash
123456789101112
# 查看系统内核信息
uname -a

# 查看系统发行版信息
cat /etc/os-release

# 查看系统当前时间和日期
date

# 查看系统运行时间
uptime

2. 查看磁盘信息

Bash
123456
# 查看磁盘使用情况
df -h

# 查看当前目录下各个文件和文件夹的磁盘使用情况
du -sh *

3. 查看内存信息

Bash
123
# 查看系统内存使用情况
free -h

六、网络管理

1. 查看网络配置

Bash
12345678
# 查看网络接口信息
ifconfig
ip addr

# 查看路由表
route -n
ip route

2. 网络连接测试

Bash
123456
# 测试网络连通性
ping <IP 地址或域名>

# 跟踪数据包的路由路径
traceroute <IP 地址或域名>

3. 端口扫描

Bash
123
# 扫描指定主机的端口
nc -zv <IP 地址> <端口号>

七、软件包管理

1. Debian/Ubuntu 系统（使用 apt）

Bash
123456789101112131415
# 更新软件包列表
sudo apt update

# 升级已安装的软件包
sudo apt upgrade

# 安装软件包
sudo apt install package_name

# 卸载软件包
sudo apt remove package_name

# 彻底卸载软件包，包括配置文件
sudo apt purge package_name

2. Red Hat/CentOS 系统（使用 yum 或 dnf）

Bash
123456789101112
# 更新软件包列表
sudo yum update  # 旧版本
sudo dnf update  # 新版本

# 安装软件包
sudo yum install package_name  # 旧版本
sudo dnf install package_name  # 新版本

# 卸载软件包
sudo yum remove package_name  # 旧版本
sudo dnf remove package_name  # 新版本

八、文本处理

1. 查找文件内容

Bash
123456
# 在文件中查找指定字符串
grep "search_string" file.txt

# 递归在目录及其子目录下的文件中查找指定字符串
grep -r "search_string" /path/to/directory

2. 排序与统计

Bash
123456
# 对文件内容进行排序
sort file.txt

# 统计文件中的行数、单词数和字符数
wc file.txt

3. 替换文本

Bash
123
# 使用 sed 命令替换文件中的文本
sed 's/old_text/new_text/g' file.txt

九、压缩与解压

1. tar 命令

Bash
123456789101112
# 创建 tar 归档文件
tar -cvf archive.tar file1 file2 directory

# 解压缩 tar 归档文件
tar -xvf archive.tar

# 创建并压缩为 tar.gz 格式
tar -zcvf archive.tar.gz file1 file2 directory

# 解压缩 tar.gz 格式文件
tar -zxvf archive.tar.gz

2. zip 与 unzip 命令

Bash
123456
# 创建 zip 压缩文件
zip archive.zip file1 file2 directory

# 解压缩 zip 文件
unzip archive.zip

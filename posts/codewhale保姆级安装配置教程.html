CodeWhale保姆级安装配置教程

CodeWhale开源终端AI编程助手完整部署教程，DeepSeek官方API配置，解决Windows下载超时问题，三种权限模式讲解，零基础直接复刻安装，Claude Code轻量化平替。

一、CodeWhale 是什么？（通俗大白话）

CodeWhale 前身是 DeepSeek-TUI，是一款纯终端运行的开源 AI 编程助手，完全可以当作 免费轻量化 Claude Code 平替，新手零门槛上手。

很多人习惯用网页版 DeepSeek、ChatGPT 写代码，但痛点非常明显：写代码、改代码、排错需要反复复制粘贴、切换窗口，效率极低。

而 CodeWhale 直接扎根你的本地项目，无需切换软件：读代码、改文件、建页面、跑命令、自动修 Bug、梳理项目架构 全部一键完成，AI 全程接管开发流程，彻底告别手动复制粘贴。

核心优势（对比普通网页 AI）

  • ✅ 直接读取本地整个项目，完整理解代码架构，不局限单段代码
  • ✅ 自动新建/修改代码文件、生成网页、编写脚本、优化代码
  • ✅ 自动执行终端命令、捕获报错、智能分析并修复 Bug
  • ✅ 支持多轮连续任务，全程保留项目上下文，不用重复描述需求
  • ✅ 三种权限模式自由切换，可控性拉满，兼顾安全与效率
  • ✅ 最新 v0.9.3 优化缓存机制、权限规则，运行更稳定，适配更多场景

重要提醒：CodeWhale 是本地客户端工具，本身不提供模型能力，必须搭配 DeepSeek 官方 API Key 才能正常使用。

二、前期准备（4个必备条件）

正式安装前，提前准备好以下内容，全程不踩坑：

  1. Node.js LTS 长期版：提供 npm 包管理器，用于全局安装工具
  2. DeepSeek 账号 + 官方 API Key：唯一接口调用凭证（本文专属官方配置）
  3. 终端工具：Windows 推荐 PowerShell / Windows Terminal（建议管理员身份运行）
  4. 空白测试文件夹：用于首次测试功能，避免改动正式项目代码

三、第一步：安装 Node.js（所有系统通用）

CodeWhale 依托 npm 安装，必须先安装 Node.js 环境，新手直接按以下步骤操作即可：

  1. 打开官网下载 LTS 长期支持版：https://nodejs.org/zh-cn/download
  2. 安装全程默认下一步，无需修改任何配置，傻瓜式安装
  3. 关键操作：安装完成后，关闭所有打开的终端，重新打开 PowerShell（刷新环境变量）
  4. 输入以下命令验证安装，输出版本号即为成功：
Bash
123
node -v
npm -v

四、第二步：安装 CodeWhale（含GitHub超时终极解决方案）

默认官方源下载速度慢、GitHub 二进制文件极易超时，优先切换国内镜像加速，完美解决下载失败问题。

1. 切换 npm 国内镜像（必做，提速10倍+）

Bash
12
npm config set registry https://registry.npmmirror.com

2. 全局安

各 个ggWindows 高频致命坑：GitHub 下载超时/连接失败

报错现象：安装成功后，执行查看版本、启动命令，程序持续请求 GitHub，出现 ECONNRESET / ETIMEDOUT 超时、下载失败，无法启动。 根本原因：工具启动会自动拉取 GitHub 二进制文件，国内网络无法访问，无需反复重试、改代理，直接用离线部署方案根治！

✅ 终极离线解决方案（100%成功）

  1. PowerShell 执行命令，打开 CodeWhale 安装根目录
POWERSHELL
12
explorer "$(pnpm root -g)\node_modules\codewhale"
  1. 在打开的文件夹内，新建文件夹并命名为 dist
  2. 可正常联网环境下载4个核心文件，全部放入 dist 文件夹 下载地址模板：https://github.com/Hmbown/CodeWhale/releases/download/v0.9.2/[文件名] 需要下载的文件清单：
  • codewhale-artifacts-sha256.txt
  • codewhale-windows-x64.exe
  • codewhale-tui-windows-x64.exe
  • codew-windows-x64.exe
  1. 文件放置完成后，新开终端，执行验证命令
Bash
1234
codewhale --version
# 环境自检，排查所有配置问题
codewhale doctor

输出版本号、自检无报错，代表安装彻底成功，后续永久不会联网下载二进制文件。

五、第三步：获取 DeepSeek 官方 API Key

仅用官方接口，稳定无卡顿、无中转风险，新手直接照搬步骤：

  1. 打开 DeepSeek 开放平台：https://platform.deepseek.com/
  2. 登录个人账号，左侧菜单栏找到【API Keys】
  3. 点击【创建API Key】，自定义名称（推荐填写 codewhale，方便区分）
  4. 重点！复制 sk 开头的密钥，保存到记事本

密钥核心注意事项：

  • API Key 仅创建时展示一次，丢失无法找回，只能重新创建
  • 严禁截图、发群、公开分享，泄露立即删除重建，避免被盗刷
  • 账号需手动充值少量余额，接口才能正常调用（费用极低）
  • 当前支持 DeepSeek-V4-Flash（公测）、V4-Pro 双模型，适配性拉满

六、第四步：绑定配置 API（全程官方接口）

打开 PowerShell，执行专属认证命令，绑定 DeepSeek 官方模型：

Bash
12
codewhale auth set --provider deepseek

终端提示输入密钥时，粘贴刚才保存的 sk 密钥，回车确认即可。

常用认证快捷命令

Bash
123456
# 查看当前认证状态，排查配置问题
codewhale auth status

# 清除旧密钥（更换新密钥时使用）
codewhale auth clear --provider deepseek

终端显示「认证正常」，代表全部配置完成，工具可以正常使用！

七、第五步：首次启动 & 初始化设置

新建专属测试目录，避免改动正式项目，安全试水：

Bash
123456789
# 创建测试文件夹
mkdir codewhale-test

# 进入文件夹目录
cd codewhale-test

# 启动CodeWhale终端交互界面
codewhale

首次启动初始化（新手照选）

  • 语言选择：简体中文
  • 信任当前文件夹：选择 是

进入主交互界面后，底部输入框即可输入任意开发需求，AI 自动执行。

八、三种核心工作模式（新手必懂，安全关键）

工具内置三种权限模式，Tab 键快速切换，也可通过斜杠命令切换，适配所有开发场景，新手优先熟记！

Bash
1234
/mode plan    # 只读分析模式
/mode agent   # 日常推荐可控模式
/mode yolo    # 全自动无确认模式

1. Plan 只读模式｜新手首选（最安全）

  • ✅ 权限：仅读取代码、分析架构、输出方案、排查问题
  • ❌ 绝对不会修改本地文件、不会执行终端命令
  • 适用场景：阅读陌生项目、分析 Bug 原因、查看 AI 修改方案、架构设计

2. Agent 可控模式｜日常默认推荐（兼顾安全&效率）

  • ✅ 权限：读取所有文件、可修改代码、可运行终端命令
  • ✅ 所有高危操作弹窗询问确认，人工审核后再执行
  • 适用场景：90% 日常开发、写代码、调试 Bug、重构项目、功能迭代

3. YOLO 全自动模式｜谨慎使用（高权限）

  • ✅ 权限：全自动执行所有操作，无需人工确认
  • ⚠️ 风险警告：禁止在正式业务项目开启
  • 适用场景：纯测试目录、重复性自动化脚本、简单批量任务

九、零基础实战：生成课堂随机点名网页

进入 codewhale-test 目录并启动工具，复制以下完整需求发送，AI 会全自动完成开发：

全部使用中文回复。帮我生成一个课堂抽签点名网页，自动生成40个中文学生名字。 功能清单：

  1. 页面标题：课堂随机点名器
  2. 页面中央展示滚动学生姓名
  3. 按钮：开始抽签 / 停止抽签
  4. 点击停止，锁定选中学生，高亮展示
  5. 下方展示全部学生名单，标记已抽中人员
  6. 增加重置抽签记录按钮，规避短时间重复抽到同一人
  7. 使用原生HTML+CSS+JS，不引入第三方框架
  8. 页面适配教室大屏投屏，视觉醒目，仪式感更强 生成完成后，告诉我如何本地预览页面。

等待数十秒，AI 会自动创建index.html、编写全套代码、完成功能开发。任务结束后，直接双击 html 文件即可浏览器打开预览。 如需优化，直接续发指令即可：优化页面配色，放大选中文字，增加抽签动画效果

十、CodeWhale 适用场景（精准避坑）

✅ 非常适合

  • 快速生成静态网页、Demo 小工具、批量脚本
  • 梳理中小型项目架构、解读陌生开源代码
  • 修复常规 Bug、优化代码格式、精简冗余代码
  • 自动生成 README、接口注释、开发文档
  • 新手学习编程，辅助理解代码逻辑、快速上手实操

❌ 谨慎使用

  • 线上核心业务、支付、权限、资金相关复杂系统
  • 大型分布式项目、高复杂度架构迭代

复杂项目建议：先用 Plan 模式看方案，再用 Agent 模式分步执行，绝对安全。

十一、高频问题汇总（一次性解决99%报错）

问题1：codewhale 命令无法识别

解决方案：关闭所有终端重新打开，执行 pnpm setup 刷新系统环境变量即可。

问题2：持续GitHub二进制下载超时

解决方案：直接使用本文离线 dist 文件夹部署方案，无需折腾代理、镜像，根治问题。

问题3：API 调用失败、请求报错

  • 核对 API Key 是否粘贴正确、有无多余空格
  • 检查 DeepSeek 账号是否有可用余额
  • 确认密钥未过期、未手动删除重建

问题4：切换 AI 模型（Flash/Pro）

工具交互界面内执行命令，一键切换模型：

Bash
123456
# 性价比首选：日常开发、快速迭代
/config set general.model deepseek-v4-flash

# 强推理首选：复杂逻辑、算法、架构设计
/config set general.model deepseek-v4-pro

v0.9.3 新版优化了权限规则、缓存机制、终端适配，运行更稳定，是目前性价比最高的终端 AI 编程工具。

新手固定使用流程：Plan模式分析项目 → Agent模式安全开发 → 迭代优化调试 → 禁止随意开启YOLO模式
